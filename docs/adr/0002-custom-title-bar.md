# ADR-0002：自定义标题栏（标签行兼作标题行）

- 状态：Accepted
- 日期：2026-10-16
- 决策范围：UI 标题行

## 背景

主窗口顶部原有两行：系统标题栏加一行标签栏。需求是向 Windows Terminal 看齐——标签与最小化/最大化/关闭合并为一行、去掉系统标题栏，同时保留拖动、边缘缩放、吸附、系统窗口菜单等原生行为，并保证非 Windows 平台仍可用。

## 候选方案

1. 保留系统标题栏：零风险，但顶部仍是两行，目标样式无法达成。
2. 完全自绘无边框窗口（`FramelessWindowHint` 加自实现拖动/缩放/阴影）：控制力最强，但拖动、缩放、吸附、阴影、多屏与 DPI 行为都要自己维护，回归风险大。
3. 只去掉 `WS_CAPTION`、保留 `WS_THICKFRAME`，用 `WM_NCCALCSIZE` 与 `WM_NCHITTEST` 做最小原生钩子：客户区覆盖原标题栏区域，拖动、缩放、Aero Snap、双击最大化、右键系统菜单与 DWM 阴影仍由系统提供。

## 决策

采用方案 3。

- `WM_NCHITTEST`：标签行空白处返回 `HTCAPTION`，拖动、双击最大化/还原、右键系统菜单由系统原生处理；标签本身、“+”新建按钮、滚动按钮及其他控件交回默认处理，点击逐层照常传递。
- `WM_NCCALCSIZE`：最大化时客户区取 `MonitorFromWindow` 的报告工作区，多屏、任务栏与 DPI 变化下都稳定；普通状态交给默认处理（客户区即窗口矩形去掉缩放边框）。
- 应用配色方案声明：`apply_theme()` 通过 `QStyleHints::setColorScheme()` 把应用主题声明给 Qt（浅色/深色显式覆盖，“跟随系统”重置为 `Unknown` 后读取系统真实配色），Windows 平台插件据此维护原生窗口边框的沉浸式深色属性，主题切换与冷启动都立即生效。若只直写 DWM 属性而不声明配色方案，平台插件会在调色板变化时按系统配色异步覆盖该属性，深色主题顶部会残存浅色缩放边框。
- 启动可见性：主窗口在构造完成、系统标题栏移除与保存几何恢复之前必须保持隐藏；`keep_window_hidden()` 在默认几何确定后与 `bootstrap.main` 显示前各执行一次原生 `ShowWindow(SW_HIDE)`（窗口已被应用显示时保持原样，离屏与非 Windows 平台直接返回），把第一个可见帧留给应用自己的 `show()`。实测部分 Windows 启动路径（源码与打包 exe 均出现）上，主窗口会在构造中途以默认尺寸加系统标题栏提前显示约一秒再跳变到保存状态，观感是“先小窗口、再放大”。
- DWM 窗口属性兜底同步：`apply_window_theme()` 直写沉浸式深色（`DWMWA_USE_IMMERSIVE_DARK_MODE`，Win10 1903 前旧 id 19 回落），声明 Win11 圆角偏好（`DWMWA_WINDOW_CORNER_PREFERENCE`），并把 1 像素的窗口边框描边（`DWMWA_BORDER_COLOR`）改为主题的窗口底色——系统默认描边在深色主题下呈浅色细线、顶部尤其明显，取窗口底色后与界面融为一体，两个主题观感一致。属性调用失败（旧系统不支持该 id）时静默降级，不产生额外行为。
- 最小化/最大化（还原）/关闭为自绘按钮，关闭按钮悬停遵循 Fluent 约定改用红底白图标。
- 非 Windows 平台或离屏平台（`QT_QPA_PLATFORM=offscreen`）不启用原生钩子并回退系统标题栏，测试环境不依赖真实窗口消息。

## 后果

优点：

- 顶部单行，标签行信息密度最高，视觉与 Windows Terminal 一致。
- 拖动、缩放、吸附、系统菜单、阴影与任务栏行为都由系统提供，行为回归面小。
- 原生钩子只在 Windows 桌面平台生效，测试与非 Windows 平台走普通窗口路径。

约束：

- Windows 11 悬停“最大化”按钮不弹贴靠布局浮窗（自定义按钮的系统限制），可用 `Win+Z` 或拖到屏幕边缘替代。
- 窗口顶部与左右保留一圈（100% DPI 约 8px）原生缩放边框，客户区不覆盖到窗口最外沿，标题行按钮贴近但不完全顶到屏幕角。
- 原生窗口行为无法离屏自动化，交付前需真机人工验收；单元测试覆盖按钮行为、图标交换与命中判定纯函数。
- 该方案只适用于 Windows；其它平台保持系统标题栏。

## 真机验收清单

- 拖动：按住标签行空白拖动、双击最大化/还原、右键弹出系统菜单、`Alt+Space` 键盘菜单。
- 缩放：四边与四角拖动改尺寸，最大化后拖顶部边框可还原；DWM 阴影与 Win11 圆角存在。
- 吸附：拖到屏幕上边缘/左右边缘触发吸附，`Win`+方向键、`Win+Z` 贴靠布局正常。
- 多屏与 DPI：125%/150% 缩放、跨屏最大化还原、任务栏自动隐藏时不遮挡内容。
- 按钮：最小化/最大化（还原）/关闭行为正确，最大化状态变化时图标与提示同步；关闭按钮悬停红底白图标。
- DWM 观感：深色主题下窗口四周（尤其顶部）不再有白色窗缘与浅色描边细线；浅色主题与主题切换（深↔浅）后边框均正确跟随。
- 标签交互：标签、“+”、“收起设置”、“终端/分栏”、“☰”与窗口按钮点击不触发窗口拖动；标签行空白拖动不误触标签。
