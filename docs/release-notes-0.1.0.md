# QSerialTool 0.1.0 发布说明

## 状态

发布候选，Windows 与 Linux 构建、验收均已完成；Linux 串口验收使用虚拟串口，
限制见下方「已知限制」。

## 功能

- Windows/Linux 跨平台桌面界面。
- 多标签串口会话。
- 端口热插拔扫描。
- 常见及自定义串口参数。
- DTR/RTS 控制。
- 文本和 HEX 收发。
- UTF-8、GB18030、ASCII 编码。
- 时间戳、RX/TX 分色、过滤、暂停和清屏（快捷键 `Ctrl+L`）。
- 接收设置在左侧栏“接收设置”卡片中集中管理，侧栏折叠与终端/分栏切换按钮位于标签行顶部。
- 发送历史（分栏编辑器 `↑`/`↓` 导航；终端 `Shift+↑`/`Shift+↓`，普通方向键透传设备）和周期发送。
- CSV/TXT 自动日志和手动导出。
- 会话配置恢复。
- 系统/浅色/深色主题。

## 已知限制

- Windows 真实串口收发、压力与长时间稳定性验收已完成（2026-10-18）。
- Linux 已在 Ubuntu 22.04 完成单文件构建、冷启动、`xcb` 插件和明暗主题核对，
  以及基于虚拟串口的硬件用例与两小时稳定性验收（2026-10-18）；未使用真实
  USB 转串口硬件，运行中拔插等真实硬件场景待后续补充。
- Windows 单文件已在未安装 Python 的干净测试机验收；Linux 单文件在构建机以
  `env -i` 空环境近似验证，未在独立纯净系统复验。
- 不包含文件发送、Modbus 解析、脚本、日志回放和协议插件。
- 无代码签名、自动更新和遥测。
